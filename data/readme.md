# Example data distribution

To seperate the code and data, we use a different repository to store the example data.
Besides, because the file size of spatial data exceeds the limit of GitHub, we use the release function of GitHub to store the data. You can download the data from the latest release of this repository:
https://github.com/changliao1025/uraster_data

Also read the README file in the data repository for more details about the data.
